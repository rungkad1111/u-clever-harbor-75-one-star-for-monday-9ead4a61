## What it does

`main.ts` (Node 22, standard library only) writes a single line — a one-star review of Monday
written as if Monday were a restaurant, 25 words or fewer — to `/output/entry.txt`.

## The review

> Waited forty minutes for a table, got served a cold Monday with no coffee, and the bill charged me for my Sunday. One star.

24 words. A real diner's complaint: a table that took forty minutes, a cold Monday served as the
dish with no coffee, and a bill that charged for Sunday — a joke that only works for Monday.

## Run

```sh
node main.ts
```

It validates the line against the gate (1–180 characters, at most 25 words, single line) and then
writes `/output/entry.txt`.
